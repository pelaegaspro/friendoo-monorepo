# FigCraft Design Guidelines

- Design mobile frames using standard 390x844 (iPhone 14 / standard modern viewport) or 360x800.
- Use Friendoo brand tokens:
  - Primary Neon Purple: `#7C3AED`
  - Neon Coral / Pink: `#EC4899`
  - Dark Surface / Canvas: `#0B0E17`
  - Card Surface: `#161B26` with border `#262D40`
  - Text Primary: `#FFFFFF`, Secondary: `#94A3B8`, Muted: `#64748B`
  - Success Green: `#10B981`, Amber: `#F59E0B`, Danger Red: `#EF4444`
- Always group layers under meaningful parent frames.
- When generating exports, provide both the native `.figcraft` document, `.fig` Figma file, and 2x high-resolution PNG renders.
