# MCP backup

This folder contains the MCP-related Penpot assets and scripts copied from the Friendoo workspace.

The Codex configuration snapshot is intentionally redacted:

- `codex-mcp-config.redacted.toml` records the configured server shapes without live tokens.
- `codex_apps` is managed by the Codex app runtime.
- `node_repl` is a bundled Codex runtime executable, not a project-local server.
- Penpot and Pixso are remote MCP endpoints; their live credentials are not copied here.

The copied files under `workspace-root` and `scripts` preserve their original workspace locations.
